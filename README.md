# Hasamex Transcript Analyst

An analytical platform that processes 3 expert-call transcripts from a European robotic surgery market study, answers the 6-question interview guide per expert with verbatim, timestamped quotes, surfaces cross-expert themes and divergent positions, and provides interactive cross-transcript Q&A — with every claim checked against the source transcript before it surfaces.

**Live Application:** [https://kforkandarp-transcript-analyst.streamlit.app](https://kforkandarp-transcript-analyst.streamlit.app)

---

## What It Does

* **Interview Guide Matrix**: Evaluates all 6 interview guide questions independently across all 3 experts with visual coverage badges (`Direct`, `Indirect`, `Not discussed`, `Unverified`).
* **Deterministic Quote Verification**: Every quote is machine-verified as an exact, contiguous substring of the expert's turn (never the interviewer's). Paraphrases, hallucinations, and unverified attributions are dropped or flagged.
* **Turn-Anchored Timestamps**: Timestamps are extracted directly from transcript turn data, never generated by the LLM.
* **Theme & Divergence Synthesis**: Identifies consensus and disagreements across experts, preserving cases where figures look similar but the underlying scope or qualifiers differ.
* **Grounded Chat**: Free-form multi-transcript query router with explicit topic fallbacks when questions fall outside transcript coverage.

## Quick Start

### 1. Clone & Set Up Environment

```powershell
# Clone the repository
git clone https://github.com/kforkandarp/transcript-analyst.git
cd transcript-analyst

# Create and activate virtual environment
python -m venv .venv
.venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### 2. Configure Environment Variables

Create a `.env` file in the project root:

```ini, TOML
GROQ_API_KEYS=your_groq_api_key_here
LLM_SMALL_MODEL=openai/gpt-oss-20b
LLM_LARGE_MODEL=openai/gpt-oss-120b
EMBED_MODEL=BAAI/bge-small-en-v1.5
APP_PASSWORD=

```
> `APP_PASSWORD` is an optional security boundary — leave it blank to run without a login gate.

### 3. Run Verification Tests & Launch App

```powershell
# Run unit tests
pytest

# Precompute cache (content-hashed: re-running is a no-op unless raw transcripts, prompts, or models change)
python -m analyst.build_cache

# Launch Streamlit dashboard
streamlit run app.py
```

Note: Use `python -m analyst.build_cache --force` to bypass hash checks and recompute cached artifacts.

## Architecture

* **Parse**: Raw transcripts are split into timestamped turns. Interviewer vs. expert roles are resolved strictly via speaker label mapping (`role` in `Turn`).
* **Chunk**: Turns are grouped into conversational exchanges (interviewer question + expert answer). This preserves question context during retrieval while strictly marking only expert tokens as quotable.
* **Index**: Individual FAISS index partitions per transcript using local `BAAI/bge-small-en-v1.5` embeddings (CPU-executed; no text leaves the machine to generate vector representations).
* **Answer**: Relevant exchanges are retrieved per question and synthesized via Groq into structured claims with cited quotes.
* **Verify**: Every quote is checked in code against the exact expert turn it claims to cite. If a claim has zero verified quotes, the pipeline retries once; if it still fails, it is marked Unverified rather than displayed.
* **Persistence & Cache**: Guide answers, themes, and metadata are atomically stored as JSON in `data/processed/` with SHA-256 content hashing. The deployed app serves immediately from cache without live LLM calls outside of the Ask tab.

### Model Tiering

* **Routing / Decomposition** (`openai/gpt-oss-20b`): Low-latency query analysis, sub-question splitting, and transcript routing.
* **Synthesis** (`openai/gpt-oss-120b`): High-fidelity claim extraction, cross-transcript synthesis, and theme extraction passes.

---

## Hallucination Controls

* **Literal Substring Enforcement**: Quotes are matched as literal, contiguous substrings of the source turn (normalized for punctuation and whitespace variations only).
* **Role Boundary Isolation**: Interviewer text provides contextual framing during retrieval but is structurally ineligible to be quoted or attributed to an expert.
* **Deterministic Retries & Fallbacks**: If a quote fails verification, a single retry prompt is triggered. Persistent failures surface as Unverified.
* **Preserved Nuance & Scope**: Hedges, negations, and scope qualifiers (e.g., "15–20% in high-volume centres" vs. "20% nationwide") are highlighted distinctly to prevent false consensus.

## Pipeline Execution & Results

* **Coverage**: 3 transcripts processed, 18/18 interview guide cells synthesized, 9 market themes extracted.
* **Citation Accuracy**: 33/33 quotes verified on the initial build (0 dropped quotes, 0 retries required).
* **Execution Latency**: ~4 minutes for full ingestion and Map-Reduce generation over a single Groq key (inclusive of backoff handlers).

Note: Figures represent direct pipeline execution and verification outputs over the target corpus.

---

## Scaling to 30+ Transcripts

* **Vector Retrieval**: Per-transcript FAISS partitions scale horizontally without cross-transcript contamination.
* **Ingestion Cost**: Linear $O(N)$ complexity; every new transcript is processed once and cached atomically.
* **UI Considerations**: At 30+ transcripts, the current $6 \times 3$ grid will require pagination or faceted market/role filters—the retrieval and verification core already supports arbitrary scale.

---

## Known Limitations

* **Sample Size**: Insights represent 3 distinct expert perspectives, not broader statistical market distributions.
* **Timestamp Granularity**: Timestamps represent the start time of the exchange turn, not the sub-second offset of the quote within it.
* **Summary Framing**: The verifier guarantees quote veracity and speaker attribution; human review remains necessary to evaluate whether surrounding narrative summaries capture all surrounding subtext.
* **Language Support**: Tested and validated exclusively for English transcripts.
